## 🧙‍♂️ Sobre o projeto

Todo herói começa sua jornada como um simples aventureiro... até acumular **XP (pontos de experiência)** suficiente para subir de patente! 🏆

Este projeto foi desenvolvido como parte da **[Formação Lógica de Programação da DIO ]**, com o objetivo de praticar os pilares fundamentais da lógica de programação:

- 📦 **Variáveis**
- ➕ **Operadores**
- 🔁 **Laços de repetição**
- 🔀 **Estruturas de decisão**

A linguagem escolhida por mim foi Python
---

## 🎯 Objetivo do desafio

Criar um programa que recebe o **nome** e o **XP** de um herói e retorna automaticamente em qual **nível de patente** ele se encontra, seguindo a tabela abaixo:

| 🏅 Nível | XP necessário |
|:---:|:---:|
| 🔩 Ferro | até 1.000 |
| 🥉 Bronze | 1.001 – 2.000 |
| 🥈 Prata | 2.001 – 5.000 |
| 🥇 Ouro | 5.001 – 7.000 |
| 💠 Platina | 7.001 – 8.000 |
| 🌟 Ascendente | 8.001 – 9.000 |
| 👑 Imortal | 9.001 – 10.000 |
| ⚡ Radiante | acima de 10.001 |
